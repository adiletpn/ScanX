# ScanX

**Медицинский помощник первого шага. Работает полностью офлайн.**

Скан по 20-секундному видео лица → объяснение простым языком → маршрут к нужному врачу.
Ни одного облачного запроса: видео, жалобы и результаты не покидают устройство.

> ⚠️ **Демо-прототип. Не является медицинским изделием.**
> Результаты носят оценочный характер и не являются диагнозом.
> При опасных симптомах — **103** или **112**.

---

## Зачем

Главная проблема — не в том, что рядом нет врача. А в том, что человек **не знает, надо ли к нему ехать**:
тянет месяцами с серьёзным и едет через полстраны с тем, что пройдёт само.

ScanX не заменяет врача. Он отвечает на вопрос «ехать или нет, и к кому».

И делает это **без интернета** — то есть работает ровно там, где врачей тоже нет.

## Что умеет

| Модуль | Что делает |
|---|---|
| **Скан** | Пульс по видео лица (rPPG), индекс усталости, контроль качества сигнала |
| **Проба с нагрузкой** | Замер до и после физической нагрузки + скорость восстановления пульса |
| **Ассистент** | Объясняет результаты простым языком, на русском или казахском |
| **Куда идти** | Срочность (🔴/🟡/🟢), специальность врача, лист для приёма |

## Как это работает

Пульс считается методом **rPPG** (remote photoplethysmography): с каждым ударом сердца
меняется кровенаполнение кожи, и камера ловит эти микроколебания цвета лица —
слишком слабые, чтобы их заметил глаз.

```
видео → MediaPipe Face Mesh → ROI (лоб, щёки) → средние RGB по кадрам
      → интерполяция на равномерную сетку 30 Гц
      → POS (Wang et al., 2017) → полосовой фильтр 0.75–3.0 Гц
      → спектр в скользящих окнах → медиана по окнам = пульс
```

## Установка

Нужен **Python 3.12**. На 3.13+ у `mediapipe` пропал `mp.solutions.face_mesh`, проект там не заработает.

```bash
git clone https://github.com/adiletpn/ScanX.git
cd ScanX

python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Локальная модель

```bash
brew install --cask ollama-app     # или скачать с ollama.com
ollama pull gemma3:4b              # ~3.5 ГБ, один раз
```

`gemma3:4b` выбрана под 16 ГБ RAM: есть зрение, приличный русский, не выталкивает
систему в своп рядом со Streamlit и MediaPipe. Модель меняется одной строкой
в [`config.py`](config.py) (`OLLAMA_MODEL`).

## Запуск

```bash
streamlit run app.py
```

Откроется на `http://localhost:8501`.

### Запуск на телефоне

Демо идёт с телефона — так нагляднее, и камера уже под рукой.

**iPhone.** Включите Personal Hotspot, подключите к нему Mac, узнайте IP:

```bash
ipconfig getifaddr en0
streamlit run app.py --server.address 0.0.0.0
```

На телефоне откройте `http://<IP-компьютера>:8501`.

**Android.** Проще — через USB, вообще без сети:

```bash
adb reverse tcp:8501 tcp:8501
```

Затем в Chrome: `http://localhost:8501`.

> Публичный Wi-Fi площадки лучше не использовать: там часто включена изоляция
> клиентов, и телефон просто не увидит ноутбук.

### Видео с iPhone

iPhone по умолчанию пишет в HEVC, который OpenCV читает не всегда.
Проект сам перекодирует такой файл через `ffmpeg`, но надёжнее переключить заранее:
**Настройки → Камера → Форматы → «Наиболее совместимые»**.

## Структура

```
app.py              точка входа, вкладки
config.py           все константы: ROI, пороги, модель, палитра
core/
  video_io.py       чтение видео, метки времени, поворот, масштаб
  face.py           Face Mesh, ROI, ландмарки
  rppg.py           пульс
  fatigue.py        моргания, PERCLOS, зевки, индекс усталости
  quality.py        оценка качества сигнала
ai/
  ollama_client.py  HTTP-клиент к Ollama, стриминг
  prompts.py        системные промпты
ui/
  styles.py         тема и мобильная вёрстка
  components.py     карточки метрик, графики
tests/
  test_rppg.py      тесты на синтетических сигналах
demo/               демо-видео и фото (в git не попадают)
```

## Тесты

```bash
pytest tests/ -v
```

`test_rppg.py` проверяет оценку пульса на синтетике: синусоида 1.2 Гц с шумом
и трендом должна дать ~72 уд/мин, неравномерные метки времени не должны
ломать результат, слишком короткий сигнал — давать понятную ошибку.

## Ограничения

Это честный список, а не оговорка мелким шрифтом.

- **Пульс — оценка, не измерение.** Точность зависит от света, движения и камеры.
  При плохом качестве сигнала приложение не показывает число, а просит переснять.
- **Дыхание не считаем.** За 20 секунд разрешение по частоте даёт ±3 вдоха/мин —
  такой цифре нельзя доверять, поэтому её нет.
- **Модель на 4B ошибается.** Она объясняет и маршрутизирует, но не ставит диагнозы
  и не назначает лечение — это заложено в системный промпт.
- **Никаких диагнозов.** При признаках неотложного состояния первым делом — 103.
